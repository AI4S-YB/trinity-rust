- count=0 跳过；`count < min_count` → 置 0；熵 < min_entropy → 置 0（熵用 f32 公式，与 P0 位级验证版一致）
- 错误 kmer（仅 prune_error_kmers）：前向+反向对称；候选（count>0，降序）取 dominant=candidates[0].count；对每个 i≥1：`candidate/dominant < r && candidate/self_count < r`（均严格 <，f32 除）→ 入 deletion_list（**不即时置 0**，可重复入列）；遍历完统一置 0
- 调用条件：`min_kmer_count > 1 || min_any_entropy > 0 || prune_error_kmers`

### 种子列表
- 非 PARALLEL：收集 count>0 的 (kmer,count)，排序 count 降序 + 平局 kmer 值降序（显式化原版 _DEBUG 比较器；原版发布版平局为 introsort 实现定义序——我们的选择是确定性超集，注释声明）
- PARALLEL：**不排序**，保持计数容器迭代序（我们的 FxHashMap 迭代序；与原版哈希序不同——两版都 nondeterministic-by-design，靠多重集比较验证）

### compute_sequence_assemblies 主循环
- 每种子：实时查 count（排序缓存过期）→ is_good_seed_kmer（count>0 且非回文且 ≥MIN_SEED_COVERAGE 且熵 ≥MIN_SEED_ENTROPY，均严格比较按原版）→ build_contig → PARALLEL&&TWO_PHASE 时 extract_best_seed 重取种子（实时 count==0 则 continue）→ 重建 → avg_cov = `(f32)total/(len-K+1) + 0.5` 截断（**f32 算术**）→ `len >= MIN_ASSEMBLY_LENGTH && avg_cov >= MIN_ASSEMBLY_COVERAGE` 才记录 → **无论是否记录**，joined_path 全部 kmer clear_kmer
- 记录 = (total_counts, avg_cov, seed_count 快照, sequence)；输出去重 key = generateHash 低 32 位截断；header `>a{i};{avg_cov} total_counts: {tc} Seed: {seed} K: {K} length: {len}`；60 列折行；stdout
- 护栏：组装中哈希 size 不得增长（我们只置 0 不插键，天然满足；保留 debug_assert）

### 贪心核心
- build_inchworm_contig_from_seed：visitor(HashSet+canonical)；先前向 inchworm('F')；visitor.clear + 前向路径全部 add + erase(seed)；再反向 inchworm('R')；total = fwd.second + rev.second + seed_count（种子不在 path 中）；joined = reverse_path 逆序 + seed + forward_path
- inchworm 外层：每轮 visitor.erase(当前kmer)；inchworm_step(dir, (kmer,count), depth=0, max_recurse=MAX_RECURSION)；`best.second > 0` 才延伸；把 step 返回的 path（深→浅压栈）**倒序** append 进 entire_path 并 visitor.add；当前 kmer ← entire_path 末尾；entire.second += best.second；轮数 > num_total_kmers 抛错
- inchworm_step：visitor/eliminator 查重返回空；visitor.add(kmer)；`depth < max_recurse` 时取候选（count>0、!visitor、connectivity 恒过）递归（传 depth+1 与**本层 recurse_cap**），每个候选递归后 visitor.erase 回溯；paths 收集 size≥1 者：
  - paths 排序：累计 count 降序（平局序实现定义——**我们显式化为稳定排序保持收集序**，即候选序 G,A,T,C）
  - `paths[0].second == paths[1].second && paths[0].first[0] != paths[1].first[0]`（真 tie）：`recurse_cap >= 50` → tie=false + **rand()%2 二选一**（glibc random 复刻）；elif `paths[0].first.size() > best_path_length` → recurse_cap++ 继续循环；else → 取 paths[0]
  - 同分同端点 → 取 paths[0]；无 tie → paths[0]；单路径 → 它；零路径 → 空
  - 尾部：depth>0 时 push 自身 kmer + second += 进入时 count 快照（**种子 depth=0 不计**）
- 候选生成位运算：forward `(seed << (33-K)*2) >> (32-K)*2 | i`、reverse `(i << (2K-2)) | (seed >> 2)`，i=0..3 = **G,A,T,C 序**；过滤 count==0；排序 count 降序、平局保持 GATC 序
- extract_best_seed：`count > best && is_good_seed`（&& 短续，左边先行）平局取路径中更早者；找不到返回 0
- reconstruct_path_sequence：首 kmer 全串 + 后续各 1 碱基

### generateHash（sequenceUtil.cpp:422，放 trinity-common）
```rust
pub fn generate_hash(s: &[u8]) -> u64 {
    let mut hash: u32 = 0;
    let mut combined: u64 = 0;
    for &n in s {
        hash = hash.wrapping_mul(65599).wrapping_add(n as u32);
        let base_val = match n { b'G'|b'g' => 1, b'A'|b'a' => 2, b'T'|b't' => 3, b'C'|b'c' => 4, _ => 0 };
        combined += base_val;
    }
    hash ^= hash >> 16;
    (combined << 32) | (hash as u64)
}
```
（去重 key 再 `as u32` 截断——复现原版 unsigned int 接收。）

### glibc random()（TYPE_3，放 trinity-inchworm/src/glibc_rand.rs）
未 srandom → seed=1。初始化：`r[0]=seed; for i in 1..31: r[i] = (16807 * r[i-1]) % 2147483647`（Schrage，负则 +2147483647；全 i32 运算）；`r[31]=r[0]; r[32]=r[1]; r[33]=r[2]`；丢弃前 310 个输出。输出：`r[i] = r[i-31] + r[i-3]（i32 回绕）; return (r[i] as u32) >> 1`。（以 C harness 黄金验证为准修正细节。）
