## 移植契约（主控精读报告浓缩）

### 阶段序与目录布局（Trinity L1376-1990）
```
outdir/  (chdir)
├── [归一化 insilico_read_normalization/]（默认开）
├── left.fa/right.fa → both.fa（先左后右；校验字节数；prep 后删 left/right）
├── inchworm.fa（无 SS 时名 inchworm.DS.fa）+ inchworm.fa.finished
├── chrysalis/{iworm_cluster_welds_graph.txt[.sorted], GraphFromIwormFasta.out,

│   component_base_listing.txt, butterfly_commands}
└── Trinity.tmp.fasta → <outdir>.Trinity.fasta（**outdir 上一级同名拼接**）+ .gene_trans_map
```

### prep_seqs（L2743-2879）
- PE：`split(//,SS)`——RF→left='R',right='F'；FR→left='F',right='R'；**只有字符=='R' 才 revcomp**
- read 名：fq 经 seqtk `-A -R 1|2`（追 /1 /2；'R' 再加 -r）；fa 多文件循环追加；'R' 经 revcomp
- 输出 left.fa/right.fa/single.fa + .ok；多逗号输入合并
- both.fa = cat left.fa right.fa（先左后右）

### checkpoint 框架（Pipeliner.pm）
每命令：执行前 `-e checkpoint` 跳过；成功 touch；失败 stderr 回显。主线清单（精读报告 §3）——**同名同位复刻**（含 `.jellyfish_count.25.mincov1..ok`、`.iworm.25..ok`、`GraphFromIwormFasta.out.ok`、`.quantify_graph.ok`、`.butterfly.ok` 等）。

### butterfly 组件池
- listing 逐组件：`run_component(graph.out 文本, graph.reads 文本, {N:100000, L:min_contig, F:pair_dist, NO_EM_REDUCE:true, path_reinforcement_distance})` → `<base>.graph.allProbPaths.fasta`
- 线程池（-CPU/--bflyCPU 语义：默认 min(6,CPU)?——读原版 bflyCPU 计算后定）；每组件线程 `stack_size`（默认 256MB 可配——P4 审查逃生口）；catch_unwind 隔离 + 失败清单 + 非零退出
- Trinity 主线传 `--NO_EM_REDUCE --path_reinforcement_distance=<25%×F>`（L2385-2389）

### 汇总（print_butterfly_assemblies.pl）
- listing 逐 base 找 `<base>.graph.allProbPaths.fasta`；缺失 → 报错非零退出
- header 原样；`len(seq) >= min_contig_length` 过滤；**全序列字符串全局去重**（duplicate 跳过）
- gene_trans_map：`/>(\S+)/` 正则 `^(.*c\d+_g\d+)(_i\d+)` → `gene\ttrans`

### SS 全链传播表（精读报告 §8）
prep('R' revcomp) / kmer count(SS 不加 canonical) / inchworm(无 SS 加 --DS) / GFF+RTT+QG(有 SS 加 -strand) / F2DB(有 SS 加 --SS) / butterfly 无感知 / inchworm 输出文件名(无 SS=inchworm.DS.fa)

### 与原版对拍形态
两侧等价参数：`--no_bowtie --no_salmon`（我们的范围本来就没有）；归一化保留（我们有 byte-identical 版）；原版侧 PATH 需 jellyfish/seqtk（conda env）。
**已知差异传播链**（写进 eval 报告预期）：inchworm 种子平局 3-4% → 焊接图边集 → 组件划分 → butterfly 裸边播种；刀口边。评估目标：转录本序列多重集高重叠（≥95% 主序列覆盖），差异逐类归因。
