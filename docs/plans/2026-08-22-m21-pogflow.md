# M2.1 POG-Flow 引擎 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 Butterfly 的 POG 图（read-path 重叠图 + zipping 后的 SeqVertex DAG）上做流分解路径选择——获得 classic 的图质量 + flow 的路径选择策略。

**Architecture:** `run_component` 加 `PathEngine::PogFlow` 变体：跑到 `create_dag_from_overlap_layout` 后，把 `seqvertex_graph`（DiGraph）转为 `FlowGraph`，做最重路径剥离，用后缀-前缀拼接输出序列。不进 `run_butterfly_all_prob_paths`。

**Tech Stack:** 既有 trinity-butterfly + trinity-flow；trinity-butterfly 加 trinity-flow 依赖。

---

## 核心接口变更

```
trinity-butterfly::component::run_component
  ├─ PathEngine::Classic → 现有路径（不变）
  └─ PathEngine::PogFlow → create_dag_from_overlap_layout 后:
        ① DiGraph → FlowGraph 转换（节点 kmer=节点 name, 边权=edge.wei）
        ② peel_component 流分解
        ③ path_to_seq 后缀-前缀拼接
        ④ min_len 过滤 + FASTA 输出（flow::paths::to_fasta）
```

```rust
/// trinity-butterfly DiGraph → trinity-flow FlowGraph。
/// 节点 kmer = SeqVertex.name（压缩后全长序列，不等长）; 边权 = SimpleEdge.wei。
fn digraph_to_flow(g: &DiGraph) -> trinity_flow::graph::FlowGraph {
    let mut fg = trinity_flow::graph::FlowGraph::default();
    for &vid in g.vertex_ids() {
        if let Some(v) = g.get_vertex(vid) {
            fg.nodes.insert(vid as i64, trinity_flow::graph::FlowNode {
                kmer: v.name.as_bytes().to_vec(),
            });
        }
    }
    for &uid in g.vertex_ids() {
        for &vid in g.get_successors(uid) {
            if let Some(e) = g.find_edge(uid, vid) {
                fg.edges.insert((uid as i64, vid as i64), e.wei as u64);
            }
        }
    }
    fg.component_id = 0;
    fg
}
```

- [ ] **Step 3: run_component_inner 的 PogFlow 分支**

在 `create_dag_from_overlap_layout` 之后（`let result = ...` 后面）：

```rust
    if params.path_engine == PathEngine::PogFlow {
        let flow_g = digraph_to_flow(&result.seqvertex_graph);
        let kmers: Vec<(i64, Vec<u8>)> = flow_g.nodes.iter()
            .map(|(&id, n)| (id, n.kmer.clone())).collect();
        let mut all: Vec<trinity_flow::paths::PathOutput> = Vec::new();
        for comp in flow_g.weak_components() {
            if comp.len() < 2 { continue; }
            let paths = trinity_flow::peel::peel_component(&flow_g, &comp,
                &trinity_flow::peel::PeelParams { min_support: 1, min_path_nodes: 2 });
            for path in paths {
                let seq = trinity_flow::paths::path_to_seq(&path, &kmers, ctx.kmer_size);
                if seq.len() < params.min_len { continue; }
                let support = path.windows(2)
                    .map(|w| flow_g.edge_weight(w[0], w[1]).unwrap_or(0))
                    .min().unwrap_or(0);
                all.push(trinity_flow::paths::PathOutput { seq, support, path });
            }
        }
        let deduped = trinity_flow::paths::dedup_similar(all, 0.95);
        let fasta = trinity_flow::paths::to_fasta(&deduped, &params.name, 0, 60);
        return Ok(ComponentResult { all_prob_paths_fasta: fasta, num_paths: deduped.len() });
    }
```
