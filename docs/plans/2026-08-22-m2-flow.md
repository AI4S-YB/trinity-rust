## 输入输出格式（锁定）

**graph.out**（5 列 tab 分隔，首行 `Component N`）：
```
node_id \t prev_node \t edge_weight \t 24-mer \t flag
```
- node_id：1-based；DS 模式负向节点 = id + total_nodes
- prev_node = -1：图起点（虚拟 root）
- edge_weight：跨该边的 25-mer read 计数（QuantifyGraph 重写）

**graph.reads**（7 列 tab 分隔）：
```
>read_name \t pos1 \t node1 \t pos2 \t node2 \t seq \t +|-
```

**输出**：`{component}_g{gene}_i{iso}` header + 60 列折行 FASTA（与 classic allProbPaths 同格式）。

## 核心算法：最重路径剥离（Heaviest Path Peeling）

```
1. 解析 graph.out → DiGraph { nodes: id→kmer, edges: (prev→cur)→weight }
2. 弱连通分量拆分（并查集）
3. 每分量:
   a. 拓扑排序（Kahn）—— 若有环: 环上最小权边剪断成 DAG（保守处理, 记数）
   b. 加虚拟源 S（零入度节点各加 S→n 容量=该节点总入流）与汇 T
   c. 剥离循环（直至所有边剩余容量 < min_support）:
      - DAG 动态规划找 S→T 总权最大路径（weight = Σ edge_weight）
      - 该路径瓶颈 = 路径上最小剩余容量
      - 路径产出（若 bottleneck ≥ min_support 且 path_len ≥ min_len）
      - 路径上每边容量 -= bottleneck
4. 路径后处理:
   a. 相似去冗余（cd-hit 式, 复用 postprocess 思路）
   b. 输出
```

**为什么这样直击碎片化**：流守恒迫使每条产出的路径从源走到底；权重剥离保证每条边最多被消耗其读支持量（不产出幽灵路径）。

```rust
//! graph.out 解析 → 流图 + 弱连通分量 + 拓扑排序。

use std::collections::HashMap;
use trinity_common::error::CommonError;

#[derive(Debug, Clone)]
pub struct FlowNode {
    pub kmer: Vec<u8>,
}

#[derive(Debug, Default)]
pub struct FlowGraph {
    pub nodes: HashMap<i64, FlowNode>,
    /// (prev, cur) → weight; prev=-1 表示虚拟源边（不参与分量但参与拓扑起点判定）
    pub edges: HashMap<(i64, i64), u64>,
    pub component_id: u64,
}

impl FlowGraph {
    pub fn parse(data: &[u8]) -> Result<Self, CommonError> {
        let text = std::str::from_utf8(data)
            .map_err(|e| CommonError::Parse(format!("graph.out UTF-8: {e}")))?;
        let mut g = FlowGraph::default();
        for (i, line) in text.lines().enumerate() {
            if line.starts_with("Component") {
                let parts: Vec<&str> = line.split_whitespace().collect();
                g.component_id = parts.get(1).and_then(|s| s.parse().ok()).unwrap_or(0);
                continue;
            }
            let f: Vec<&str> = line.split('\t').collect();
            if f.len() < 4 {
                if i > 0 && !line.is_empty() {
                    return Err(CommonError::Parse(format!("graph.out 行格式: {line}")));
                }
                continue;
            }
            let node: i64 = f[0].parse().map_err(|_| CommonError::Parse(format!("node id: {}", f[0])))?;
            let prev: i64 = f[1].parse().map_err(|_| CommonError::Parse(format!("prev id: {}", f[1])))?;
            let w: u64 = f[2].parse().unwrap_or(0);
            g.nodes.entry(node).or_insert(FlowNode { kmer: f[3].as_bytes().to_vec() });
            if prev >= 0 {
                g.nodes.entry(prev).or_insert(FlowNode { kmer: Vec::new() });
                g.edges.insert((prev, node), w);
            }
        }
        // 填充 prev 节点的 kmer（其在以 node 身份出现时有值）
        let mut kmers: HashMap<i64, Vec<u8>> = HashMap::new();
        for (&id, n) in &g.nodes {
            if !n.kmer.is_empty() { kmers.insert(id, n.kmer.clone()); }
        }
        for (id, n) in g.nodes.iter_mut() {
            if n.kmer.is_empty() {
                n.kmer = kmers.get(id).cloned().unwrap_or_default();
            }
        }
        Ok(g)
    }

    pub fn edge_weight(&self, prev: i64, cur: i64) -> Option<u64> {
        self.edges.get(&(prev, cur)).copied()
    }

    /// 邻接表（前向）
    pub fn successors(&self, id: i64) -> Vec<i64> {
        let mut v: Vec<i64> = self.edges.keys()
            .filter(|&&(p, _)| p == id)
            .map(|&(_, c)| c).collect();
        v.sort_unstable();
        v
    }

    pub fn predecessors(&self, id: i64) -> Vec<i64> {
        let mut v: Vec<i64> = self.edges.keys()
            .filter(|&(_, c)| c == id)
            .map(|&(p, _)| p).collect();
        v.sort_unstable();
        v
    }

    /// 弱连通分量（并查集, 无向）
    pub fn weak_components(&self) -> Vec<Vec<i64>> {
        let mut parent: HashMap<i64, i64> = HashMap::new();
        for &id in self.nodes.keys() { parent.insert(id, id); }
        fn find(p: &mut HashMap<i64, i64>, x: i64) -> i64 {
            let mut r = x;
            while p[&r] != r { r = p[&r]; }
            let mut c = x;
            while p[&c] != r { let nxt = p[&c]; p.insert(c, r); c = nxt; }
            r
        }
        for &(u, v) in self.edges.keys() {
            let (ru, rv) = (find(&mut parent, u), find(&mut parent, v));
            if ru != rv { parent.insert(ru, rv); }
        }
        let mut groups: HashMap<i64, Vec<i64>> = HashMap::new();
        for &id in self.nodes.keys() {
            groups.entry(find(&mut parent, id)).or_default().push(id);
        }
        let mut out: Vec<Vec<i64>> = groups.into_values().collect();
        for v in out.iter_mut() { v.sort_unstable(); }
        out.sort_by_key(|v| v[0]);
        out
    }

    /// 分量内 Kahn 拓扑排序（有环返回 None）
    pub fn toposort_component(&self, comp: &[i64]) -> Option<Vec<i64>> {
        let set: std::collections::HashSet<i64> = comp.iter().copied().collect();
        let mut indeg: HashMap<i64, usize> = HashMap::new();
        for &id in comp { indeg.insert(id, 0); }
        for &(u, v) in self.edges.keys() {
            if set.contains(&u) && set.contains(&v) {
                *indeg.entry(v).or_default() += 1;
            }
        }
        let mut queue: std::collections::BinaryHeap<std::cmp::Reverse<i64>> =
            indeg.iter().filter(|(_, &d)| d == 0).map(|(&id, _)| std::cmp::Reverse(id)).collect();
        let mut order = Vec::with_capacity(comp.len());
        while let Some(std::cmp::Reverse(id)) = queue.pop() {
            order.push(id);
            for succ in self.successors(id) {
                if let Some(d) = indeg.get_mut(&succ) {
                    *d -= 1;
                    if *d == 0 { queue.push(std::cmp::Reverse(succ)); }
                }
            }
        }
        if order.len() == comp.len() { Some(order) } else { None }
    }
}
```

```rust
//! 最重路径剥离（DAG 动态规划 + 瓶颈减流）。

use std::collections::HashMap;
use crate::graph::FlowGraph;

pub struct PeelParams {
    pub min_support: u64,
    pub min_path_nodes: usize,
}

/// 分量内剥离。返回路径列表（node id 序列, 源→汇）。
/// 注：graph 自身不被修改（在副本的 capacity 上操作）。
pub fn peel_component(g: &FlowGraph, comp: &[i64], p: &PeelParams) -> Vec<Vec<i64>> {
    let order = match g.toposort_component(comp) {
        Some(o) => o,
        None => return handle_cycle(g, comp, p), // 环 → 剪最小边重试
    };
    // 剩余容量
    let mut cap: HashMap<(i64, i64), u64> = g.edges.iter()
        .filter(|((u, v), _)| comp.contains(u) && comp.contains(v))
        .map(|(&k, &w)| (k, w)).collect();

    let mut paths = Vec::new();
    loop {
        // DAG DP: best[v] = (最大总权, 前驱)
        let mut best: HashMap<i64, (u64, Option<i64>)> = HashMap::new();
        for &v in &order {
            let mut bv = (0u64, None);
            for pred in g.predecessors(v) {
                if let Some(&c) = cap.get(&(pred, v)) {
                    if c == 0 { continue; }
                    if let Some(&(bp, _)) = best.get(&pred) {
                        let tot = bp.saturating_add(c);
                        if tot > bv.0 { bv = (tot, Some(pred)); }
                    }
                }
            }
            best.insert(v, bv);
        }
        // 汇 = 分量中无后继（或后继容量全 0）且 best > 0 的节点中 best 最大者
        let mut sink = None;
        let mut sink_w = 0u64;
        for &v in &order {
            let succs: Vec<i64> = g.successors(v).into_iter()
                .filter(|s| cap.get(&(v, *s)).copied().unwrap_or(0) > 0).collect();
            if succs.is_empty() {
                if let Some(&(bv, _)) = best.get(&v) {
                    if bv > sink_w { sink_w = bv; sink = Some(v); }
                }
            }
        }
        let sink = match sink { Some(s) if sink_w > 0 => s, _ => break };
        // 回溯路径
        let mut path = vec![sink];
        let mut cur = sink;
        while let Some(Some(pred)) = best.get(&cur).map(|(_, p)| *p) {
            path.push(pred);
            cur = pred;
        }
        path.reverse();
        // 瓶颈 = 路径相邻对的最小剩余容量
        let mut bottleneck = u64::MAX;
        for w in path.windows(2) {
            let c = cap.get(&(w[0], w[1])).copied().unwrap_or(0);
            if c < bottleneck { bottleneck = c; }
        }
        if bottleneck == u64::MAX || bottleneck < p.min_support || path.len() < p.min_path_nodes {
            break;
        }
        // 减流
        for w in path.windows(2) {
            if let Some(c) = cap.get_mut(&(w[0], w[1])) {
                *c = c.saturating_sub(bottleneck);
            }
        }
        paths.push(path);
    }
    paths
}

/// 有环分量的保守处理: 全分量最小权边剪断 → 递归 peel
fn handle_cycle(g: &FlowGraph, comp: &[i64], p: &PeelParams) -> Vec<Vec<i64>> {
    let set: std::collections::HashSet<i64> = comp.iter().copied().collect();
    let min_edge = g.edges.iter()
        .filter(|((u, v), _)| set.contains(u) && set.contains(v))
        .min_by_key(|(_, &w)| w);
    match min_edge {
        Some(( &(u, v), _)) => {
            let mut g2 = FlowGraph { nodes: g.nodes.clone(), edges: g.edges.clone(), component_id: g.component_id };
            g2.edges.remove(&(u, v));
            peel_component(&g2, comp, p)
        }
        None => Vec::new(),
    }
}
```

```rust
//! 路径 → 序列转换 + 相似去冗余 + FASTA 输出。

pub struct PathOutput {
    pub seq: Vec<u8>,
    pub support: u64,
    pub path: Vec<i64>,
}

/// 首节点全 kmer + 后续节点各取末 1 碱基（kmer 等长前提）
pub fn path_to_seq(path: &[i64], kmers: &[(i64, Vec<u8>)], _k: usize) -> Vec<u8> {
    let map: std::collections::HashMap<i64, &[u8]> = kmers.iter().map(|(a, b)| (*a, b.as_slice())).collect();
    let mut seq = Vec::new();
    for (i, &id) in path.iter().enumerate() {
        if let Some(kmer) = map.get(&id) {
            if i == 0 {
                seq.extend_from_slice(kmer);
            } else {
                seq.push(*kmer.last().unwrap_or(&b'A'));
            }
        }
    }
    seq
}

/// 简化 cd-hit 式去冗余: 逐位同一率 ≥ threshold → 保留高 support
pub fn dedup_similar(paths: Vec<PathOutput>, threshold: f64) -> Vec<PathOutput> {
    let mut sorted = paths;
    sorted.sort_by(|a, b| b.support.cmp(&a.support));
    let mut out: Vec<PathOutput> = Vec::new();
    for p in sorted {
        let dup = out.iter().any(|q| {
            let min_len = p.seq.len().min(q.seq.len());
            if min_len == 0 { return false; }
            let same = p.seq.iter().zip(q.seq.iter())
                .take(min_len).filter(|(a, b)| a == b).count();
            (same as f64 / min_len as f64) >= threshold
        });
        if !dup { out.push(p); }
    }
    out
}

pub fn to_fasta(paths: &[PathOutput], comp: &str, gene: usize, wrap: usize) -> String {
    let mut s = String::new();
    for (i, p) in paths.iter().enumerate() {
        s.push_str(&format!(">{}_g{}_i{} len={} path=[{}]\n",
            comp, gene + 1, i + 1, p.seq.len(),
            p.path.iter().map(|x| x.to_string()).collect::<Vec<_>>().join(",")));
        for chunk in p.seq.chunks(wrap) {
            s.push_str(&String::from_utf8_lossy(chunk));
            s.push('\n');
        }
    }
    s
}
```

```rust
//! 顶层流分解引擎: graph.out + graph.reads → FASTA。

use trinity_common::error::CommonError;
use crate::graph::FlowGraph;
use crate::peel::{peel_component, PeelParams};
use crate::paths::{dedup_similar, path_to_seq, to_fasta, PathOutput};

pub struct FlowParams {
    pub min_len: usize,          // 最短输出
    pub min_support: u64,        // 路径瓶颈下限
    pub dedup_threshold: f64,    // 去冗余同一率
    pub k: usize,                // kmer 长
}

impl Default for FlowParams {
    fn default() -> Self {
        FlowParams { min_len: 200, min_support: 2, dedup_threshold: 0.95, k: 24 }
    }
}

pub fn run_flow_component(
    graph_out: &str,
    _graph_reads: &str,   // M2 首版不用 reads（纯流）; PE 约束为 M2.1 迭代项
    p: &FlowParams,
) -> Result<String, CommonError> {
    let g = FlowGraph::parse(graph_out.as_bytes())?;
    let kmers: Vec<(i64, Vec<u8>)> = g.nodes.iter()
        .filter(|(_, n)| !n.kmer.is_empty())
        .map(|(&id, n)| (id, n.kmer.clone())).collect();

    let mut all_outputs: Vec<PathOutput> = Vec::new();
    for comp in g.weak_components() {
        // 跳过太小的分量（首末节点 < 2 或估算长度 < min_len 的 2/3）
        if comp.len() < 2 { continue; }
        let paths = peel_component(&g, &comp, &PeelParams {
            min_support: p.min_support,
            min_path_nodes: 2,
        });
        for path in paths {
            let seq = path_to_seq(&path, &kmers, p.k);
            if seq.len() < p.min_len { continue; }
            let support = path.windows(2)
                .map(|w| g.edge_weight(w[0], w[1]).unwrap_or(0))
                .min().unwrap_or(0);
            all_outputs.push(PathOutput { seq, support, path });
        }
    }
    let deduped = dedup_similar(all_outputs, p.dedup_threshold);
    Ok(to_fasta(&deduped, &format!("c{}", g.component_id), 0, 60))
}
```
