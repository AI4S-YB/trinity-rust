# 真实数据基准（高深度轮）：拟南芥 chr5 ~70× 覆盖（2026-08-20）

## 数据与流程

- **数据**：DRR200069（拟南芥 MiSeq PE 76bp，24.16M reads）；hisat2 比对 TAIR10
  （97.8%）→ **chr5 提取 5,798,596 PE 对**（约为低深度轮的 28 倍，~70× 转录组覆盖）
- **参照**：StringTie 2（同 reads + chr5 注释，参照引导）→ 8,712 条去重转录本
- **评估**：minimap2 asm5，恢复率按参照最佳命中分档；精确度按 de novo 碱基 ≥95% id
  比上参照的比例（口径同低深度轮）
- 8 线程 / 8GB 上限 / 双方默认参数（--no_bowtie --no_salmon）；组装段耗时
  我们 ~28 分钟（12:39→13:07）、原版 ~48 分钟（12:39→13:27，含尾部 IO）

## 结果（对 StringTie 参照）

| 指标 | trinity-rust（经典单遍） | 原版 v2.15.2（递归默认） | 相对差 |
|---|---|---|---|
| 转录本数 | 7,831 | 8,847 | 原版 +13% |
| 总 bp | 9.41 Mb | 11.57 Mb | 原版 +23% |
| N50 | 1,833 | 1,952 | 原版 +6.5% |
| **全长恢复（≥95%cov&≥95%id）** | **720 (8.3%)** | **790 (9.1%)** | 原版 +9.7% |
| ≥90% 恢复 | 1,496 (17.2%) | 1,599 (18.4%) | 原版 +6.9% |
| ≥70% 恢复 | 3,192 (36.6%) | 3,291 (37.8%) | 原版 +3.1% |
| **精确度（碱基级）** | **80.5%** | **76.9%** | **我们 +3.6pp** |
| 组装段 wall | ~28 min | ~48 min | 我们快 1.7× |

双方输出相互重叠：精确交集 4,626 条（覆盖原版 52.3% / 覆盖我们 59.1%）——高深度下
分歧加大（低深度轮为 86-88%）：覆盖越高、歧义结构越多，两套管线的路径选择差异被放大
（跨架构 + tie-break 双重因素，见 docs/architecture-discovery.md）。

## 判定（对照低深度轮的"平手"）

1. **高深度下分出温和差距**：原版全长恢复多 ~10%（790 vs 720），我们精确度高 ~3.6 个
   百分点且总输出更紧凑（少 13% 转录本、少 19% 碱基）。呈"原版多拼全 / 我们拼得准"的
   权衡形态。
2. 差距的结构性来源有两层：(a) **架构差**——原版默认为递归式（分区重组装利于高深度下
   的全长度量），我们是经典单遍；(b) 经典路径内部的 tie-break 差异。低深度轮两者收敛
   （歧义少），高深度轮分歧显现，与重叠度 86%→52% 的走势一致。
3. 绝对恢复率（8-9% 全长）仍受对比口径压制：StringTie 参照引导 + 同 reads，de novo
   对其"完整转录本模型"的重建本就困难（行业口径里 de novo vs 参照引导通常即如此）。

## 与低深度轮（2.4×）合看

| 覆盖 | 全长恢复（我们/原版） | 精确度（我们/原版） | 双方重叠 |
|---|---|---|---|
| ~2.4× | 111 / 110（平手） | 85.3% / 84.1% | 86-88% |
| ~70× | 720 / 790（-9.7%） | 80.5% / 76.9%（+3.6pp） | 52-59% |

使双方同为递归架构后重新对拍。
